Sistema de Triage – Versión Digital
Proyecto de digitalización del triage para hospital público.
Demo local (FastAPI + Docker-ready)

Esta interfaz permite registrar los datos de la ficha de triage, calcular un riesgo simplificado (ROJO / AMARILLO / VERDE) y dejar listo el sistema para integrar en el futuro un modelo de Machine Learning.

  • Ingreso de datos de la ficha institucional.
  • Cálculo de score y color de triage.
  • Listado de registros guardados en archivo JSON.
